What it does

Agents that don't stop when your laptop does

Lid closed · server rebooted · still running
Survives sleep and reboots

Agents run on your server under herdr. After a reboot they come back in the same layout and pick up the same conversation.

One key: prefix + shift + v
Move a running agent to the server

The agent, its conversation and its folder move over. The folder stays in sync both ways, so the work shows up on your laptop.

Add an issue on the board. FEMME gives it a branch and a Claude Code session, then opens the pull request.

Live terminals in the browser, and a notification on your phone when an agent is waiting for you or done.
