Open source · by Exposure

FEMME

Keeps Claude Code, Codex and Pi running under herdr on your own Ubuntu server, so they keep working while your laptop sleeps. Hand them tasks from the terminal, a web board or an HTTP API.
laptop · Linux or macOS
server · Ubuntu 24.04, x86_64 or arm64
license · Apache-2.0
A bot hands FEMME a task
$ curl -X POST $FEMME/api/agents/instinct \
    -H "Authorization: Bearer $KEY" \
    -H "Content-Type: application/json" \
    -d '{"text":"fix the signup form","repo":"example-org/app"}'
{"pane_id":"instinct~w3:p1","status":"working"}

$ curl -H "Authorization: Bearer $KEY" $FEMME/api/agents/instinct \
    | jq .message
"changes ready, not pushed to main: read the report,
 then POST /api/agents/instinct/push or /discard"

$ curl -X POST $FEMME/api/agents/instinct/push ...
# Claude commits the task as one commit and pushes to main
